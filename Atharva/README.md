# Assignment 15 - Real-Time Live Auction & Bidding Engine

A real-time auction platform built using **Node.js, Express.js and Socket.io** with live bidding, outbid notifications, countdown timers and anti-snipe protection.

## 🚀 Live Deployment

**Frontend:**  
https://assignment-15-realtime-auction-plat.vercel.app/

**Backend:**  
https://assignment-15-realtime-auction-platform-icla.onrender.com

## 🛠️ Tech Stack

- Node.js
- Express.js
- Socket.io
- CORS
- JavaScript
- In-Memory State

## ✨ Features

- 🔨 Real-time bidding
- 💰 Bid validation
- 📢 Outbid notifications
- ⏱️ Live countdown timer
- 🛡️ Anti-snipe timer extension
- 👥 Live viewer count
- 📜 Bid history
- 🏆 Automatic auction completion
